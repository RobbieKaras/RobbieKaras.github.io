ClawDeck is a Node/Express dashboard, wrapped in a native Electron app, that
installs and manages a self-hosted AI agent (NanoClaw) on someone's own Mac —
a guided setup wizard, multi-bot creation, Telegram/Discord connections, and
a local credential vault, all packaged as a normal double-clickable app
instead of something you run from a terminal.
